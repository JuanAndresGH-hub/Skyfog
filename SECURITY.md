# Security policy

SkyFog is a client-only rendering mod and does not add network services.

Please use GitHub's **Private vulnerability reporting** feature at
`https://github.com/JuanAndresGH-hub/Skyfog/security/advisories/new`.
Include the affected version, Minecraft/Fabric versions, steps to reproduce,
and a minimal log or configuration sample without personal credentials.

The repository owner must enable it under **Settings -> Security -> Advanced
Security -> Private vulnerability reporting**. If the option is unavailable,
use a private GitHub Security Advisory draft rather than a public issue.

Do not include access tokens, account credentials, or private server
information in reports.
